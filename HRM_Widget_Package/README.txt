=====================================================
          HRM LIVE DESKTOP WIDGET PACKAGE
=====================================================

HOW TO INSTALL:
1. Double-click "Setup.exe" (or run "Setup.bat").
2. Follow the prompt to enter your HRM API Token.
3. Click "Install Now".
4. The widget will install to C:\HRM_Widget and launch immediately on your desktop.
5. It is automatically registered in Windows Startup to launch on boot.

HOW TO UNINSTALL:
- Option A: Double-click "Uninstall.exe" inside this folder or in C:\HRM_Widget.
- Option B: Go to Windows "Settings > Apps > Installed apps" (or Control Panel > Programs and Features) and click "Uninstall" on HRM Live Widget.
- Option C: Click "Uninstall HRM Widget" from the Start Menu -> Programs -> HRM Widget folder.

PACKAGE CONTENTS:
- Setup.exe        : Standalone graphical installer
- Uninstall.exe    : Standalone uninstaller
- HRM_Widget.exe   : The standalone HRM Live Desktop Widget
- Theme Assets     : Batman, Spider-Man, Spider-Man V2, Eren Jaeger themes
- app.ico          : Application Icon
- Setup.bat        : Optional command-line launcher for setup
- Uninstall.bat    : Optional command-line launcher for uninstall
